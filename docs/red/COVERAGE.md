# What the Red campaign exercises

## Executable evidence

| Area | What to check |
|---|---|
| Campaign rules | Named things, fields, derived adjectives, typed verbs, worked-out values, arithmetic, conditions and reactions govern the parcel, the road gate, battles and the badge. Controller recordings for all three starters verify the reward and the second conversation with Brock. The tests load the full campaign book and render the final input for each starter. The Edge replay also draws the intermediate frames. [Campaign tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_campaign.py) · [Browser replay](https://github.com/monstercameron/EnglishScript/blob/main/tools/check_red_browser.cjs) |
| Chapters and facts | The campaign groups chapters from the same book in a single import. Species stats, move powers and field signs use keyed facts. Evolution looks up the highest level threshold reached for the starting species. Named fields keep each character’s voice, background and responses together. [Campaign imports](main.english) · [Evolution and battle](battle.english) · [Character profiles](characters.english) · [Import tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_grouped_imports.py) · [Fact-table tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_fact_tables.py) |
| Procedural drawing | English loops, text operations and page-library verbs draw the 160×144 screen. Fixtures assert glyph pixels, two-line captions and re-rendering after a restored save. [Lettering fixture](lettering_test.english) · [Restore tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_replay.py) |
| Party and items | Controller tests cover pickups, single-use rewards, capture restrictions, party switching and combat effects. The conversation tests visit every mapped character placement and compare quest fields before and after asking a question. [Bag tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_pack.py) · [Party tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_party.py) · [People tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_people.py) |
| Three thinking systems | System 0 finds the character at the facing tile or across a counter and supplies that character’s background, voice, and current story facts. Jev judges how that character hears the player’s words. GPT-6 Luna uses the verdict to answer in character. The browser displays the paged answer in the game and preserves the underlying story conversation. [Companion book](companion_model.english) · [Perception tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_companion_model.py) · [Conversation tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_conversation.py) |
| Sound | Grouped choices select the score. An active battle gets the leader, wild, or trainer track. Outside battle, the opening and title screens have their own scores. Other modes use the current place, so opening the bag in Pewter Gym keeps the gym music. The browser synthesizes the notes, effects and species cries. [Soundtrack rules](main.english) · [Music routing tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_music.py) · [Event tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_sound_events.py) · [Synth tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/red_audio.test.js) |
| Red reference | The campaign tests cover the parcel cutscene, Town Map, trainer teams, Brock’s moves and one-time rewards. A separate comparator replays reference input on the original English Red ROM and records camera position, facing, party presence and pixel differences. [Story tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_story_reference.py) · [Battle tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_battle_reference.py) · [Checkpoint comparator](https://github.com/monstercameron/EnglishScript/blob/main/tools/compare_red_segment.py) |
| Async work and storage | A Pyodide worker accepts controller events. The browser requests live dialogue separately and discards late responses after a new question, movement or restart. Manual SAVE uses local storage and Cache Storage. The Field Lab also has a fixture for movement while a recorded model answer is pending. [Browser shell](main.js) · [Save cache tests](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_save_cache.cjs) · [Field Lab test](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_boulder.py) |

Run `python -m unittest discover -s tests` from the repository. Run `python -m englishscript docs/red/lettering_test.english --test` for the English-language pixel and caption assertions. The recorded journeys start with an empty game.

The reference controller recording starts at emulator boot and runs for 265,170 original frames. Charmander defeats Brock’s level 12 Geodude and level 14 Onix, and the trainer receives ₽1,386, the Boulder Badge and one TM34. The EnglishScript recordings verify those rewards with Bulbasaur, Charmander and Squirtle. The frame comparator uses the Charmander run for its paired checkpoints. [Original controller recording](https://github.com/monstercameron/EnglishScript/blob/main/tests/fixtures/red-segment-reference.json) · [EnglishScript campaign recordings and assertions](https://github.com/monstercameron/EnglishScript/blob/main/tests/test_red_campaign.py)

## Open benchmark requirements

- The syntax checklist contains 407 structural checks plus lexical and refusal cases. The campaign lacks per-variant evidence for that checklist and for all twelve recoverable error kinds. Examples still needing campaign fixtures include `Try` recovery and `Fail again`, kept values, settled hooks, rules and sibling-book imports. [Syntax exercise checklist](https://github.com/monstercameron/EnglishScript/blob/main/apps/boulder/EnglishScript%20-%20Syntax%20exercise%20checklist.md)
- Equal-information comparisons between model-controlled trainers, combinations of different model orderings, language-level structured concurrency, parallel battle simulations and a deterministic virtual clock still need fixtures. [Benchmark plan](https://github.com/monstercameron/EnglishScript/blob/main/apps/boulder/EnglishScript%20-%20The%20Boulder%20Badge%20benchmark%20plan.md)
- Exact cartridge graphics, sound, battle randomness, timing and sustained 60 fps remain open. The original and EnglishScript use independent input clocks. Compare frames after aligning the map, position, facing and dialogue or battle phase. Run `python tools/compare_red_segment.py --rom PATH --out report.json` with PyBoy 2.9.0 and the matching local ROM. The comparator returns status 1 for a measured mismatch and status 2 for an invalid run. [Frame comparator](https://github.com/monstercameron/EnglishScript/blob/main/tools/compare_red_frames.py) · [Bedroom controller trace](https://github.com/monstercameron/EnglishScript/blob/main/tests/fixtures/red-bedroom-trace.json)
